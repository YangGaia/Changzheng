# Changzheng
# 《长征路上的选择》游戏介绍说明

## 为纪念长征胜利90周年而作

2026年10月，我们迎来中国工农红军长征胜利90周年。90年前，红军将士穿越险山、大河、草地和雪山，用坚韧和信仰完成战略转移；90年后，这段历史仍提醒我们，普通人也能在困难时刻承担责任、守护同伴、坚持信念。

《长征路上的选择》正是围绕这个纪念意义制作的桌面视觉小说。游戏以1934年10月从瑞金等地出发为起点，以1936年10月会宁、将台堡地区会师为终点，让玩家在八章中完成完整旅程。它把镜头放到一名虚构青年通讯员身上：他不是决策者，而是负责送消息、记同伴、连接队伍的普通一员。视角足够小，前行和互助才变得具体可感。

## 游戏内容

全作共八章，依时间顺序展开。第一章从瑞金出发前的准备写起，玩家要核对送信任务、归还借物、询问路线。第二章进入湘江严峻形势中的行军与坚持。第三章《再往前走》呈现遵义会议后通讯员感受到的队伍变化。第四章《跟着变化走》写四渡赤水期间的追送通知。第五章《借一双手渡河》转到金沙江皎平渡，突出船工、伤员和协作。第六章《桥头之前》以后方联络点视角呈现飞夺泸定桥。第七章《把队伍带过去》穿越雪山与草地，抵达吴起镇。第八章《会师的消息》在会宁与将台堡之间传递胜利讯息，最终汇入长征胜利结局。

每章都有三条情境选择，对应不同联络方法、接应安排或人物关系。选择会影响粮食、体力、士气、群众支持四项状态，也会改变后续对白，但不会篡改历史主线。玩家能感受行动的局部差别，却不能改写湘江、遵义、金沙江、泸定桥、雪山草地或会师的结果。资源只表示虚构小队状态，不是历史数据或思想评价。

## 纪念价值与玩法特色

在纪念长征胜利90周年时，我们希望游戏带来的不只是知识记忆，而是行动体验。玩家要面对“谁先过河”“伤员如何安置”“消息怎样核实”“接应在哪里”等问题。这些问题没有爽感，却有真实责任。它们把长征精神转化成可参与的判断：遇事先弄清情况，顾及同伴，依靠群众，继续前进。

游戏采用手绘风格场景与人物立绘、逐字对白、自动播放、回看本章、全屏阅读、自动存档和8个手动存档位。开始界面与设置界面署名制作团队“无敌舒畅”，成员为杨宇轩、吴笛畅、秦戌远、赵柯杰、姜景文。游戏可在Windows x64离线运行，双击便携版exe即可开始旅程。

## 说明

剧中人物、具体通讯任务和分支对白均为虚构；历史事件、地点和关键日期按时间顺序呈现。游戏以互动方式向长征胜利90周年致敬。愿玩家走完这程后记住的不只是路线图，还有普通人的选择与坚持。
